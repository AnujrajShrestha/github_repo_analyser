## **1. Overall Architecture**
This is a **modular, agent-based data analysis pipeline** that leverages:
- **LangChain** for LLM orchestration
- **Pandas/Numpy** for data processing
- **Matplotlib/Seaborn** for visualization
- **Pydantic** for data validation
- **Python-dotenv** for environment management

The system follows a **pipeline-based workflow** where multiple AI agents collaborate to analyze a dataset and generate insights.

## **3. Responsibilities of Each Module**

### **🔹 Pipeline (`pipeline.py`)**
- **Entry point** for the analysis workflow
- Coordinates the execution of different agents
- Manages the sequence of operations (EDA → Visualization → Correlation → Summary)

### **🔹 Agents (`agents.py`)**
- **EDA Agent**: Performs initial data exploration (missing values, data types, basic statistics)
- **Visualization Agent**: Generates plots (histograms, scatter plots, box plots, etc.)
- **Correlation Agent**: Computes and visualizes feature correlations
- **Summary Agent**: Generates a textual summary of findings

### **🔹 Tools (`tools.py`)**
- **Data Loading**: Reads CSV files into Pandas DataFrames
- **Data Cleaning**: Handles missing values, outliers, etc.
- **Statistical Analysis**: Computes mean, median, standard deviation, etc.
- **Visualization Helpers**: Generates Matplotlib/Seaborn plots

### **🔹 Environment (`.env`)**
- Stores API keys (e.g., Groq, MistralAI)
- Manages configuration settings

### **🔹 Visualizations (`plots/`)**
- Stores generated plots (PNG/JPG)
- Organizes outputs for reporting

### **🔹 Sample Data (`Housing.csv`)**
- Provides a default dataset for testing
- Can be replaced with user-provided CSV files

---

## **4. Data Flow**
1. **Input**: CSV file (`Housing.csv` or user-provided)
2. **Pipeline Initialization**: Loads data and initializes agents
3. **EDA Agent**:
   - Analyzes dataset structure (columns, data types, missing values)
   - Computes basic statistics (mean, median, std dev)
4. **Visualization Agent**:
   - Generates plots (histograms, scatter plots, box plots)
   - Saves plots to `plots/`
5. **Correlation Agent**:
   - Computes feature correlations
   - Generates a heatmap
6. **Summary Agent**:
   - Generates a textual report (`result.txt`)
7. **Output**: Visualizations + Summary report

```python
from pathlib import Path
from typing import Optional, Dict, Any
import pandas as pd
import logging

logger = logging.getLogger(__name__)

class DataAnalyzer:
    """Handles data analysis operations on CSV files."""

    def __init__(self, csv_path: str, max_file_size_mb: int = 100):
        """
        Initialize the data analyzer.

        Args:
            csv_path: Path to the CSV file
            max_file_size_mb: Maximum allowed file size in MB
        """
        self.csv_path = Path(csv_path)
        self.max_file_size = max_file_size_mb * 1024 * 1024  # Convert to bytes

    def validate_file(self) -> bool:
        """Validate the input CSV file."""
        if not self.csv_path.exists():
            raise FileNotFoundError(f"File not found: {self.csv_path}")

        if self.csv_path.stat().st_size > self.max_file_size:
            raise ValueError(f"File too large. Max size: {self.max_file_size_mb}MB")

        return True

    def load_data(self) -> pd.DataFrame:
        """Load and validate CSV data."""
        self.validate_file()

        try:
            df = pd.read_csv(self.csv_path)
            logger.info(f"Successfully loaded data with shape: {df.shape}")
            return df
        except Exception as e:
            logger.error(f"Error loading CSV file: {e}")
            raise
```
